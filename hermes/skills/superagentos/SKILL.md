# Super Agent OS

Use [Artifacts](../super-artifacts/SKILL.md) to publish and read submissions.
Use [Mail](../super-agent-mail/SKILL.md) to read and send screened mail.
Each uses its own key and tool server. Do not substitute one product’s key for another.
Ask the person to connect products in **Settings → Plugins → Super Agent OS** (desktop or web app) or the Super Agent OS dashboard tab; never edit Hermes config yourself.
Graph is early access and is not offered by this package. Mail webhooks are not available yet.
